# 基础品牌提案

## 品牌定位

- 中文站名（首选）：商情星图
- 英文名（暂用）：BizOrbit
- 完整副标题：通用商业情报与商机平台

## 视觉方向

- 主色：深蓝 + 青绿
- 标志概念：以点、星图或雷达为核心元素，保持简洁、易识别
- 使用原则：先形成独立品牌系统，再经审查逐步替换界面资产；本提案不直接替换上游 Logo

## 风险与边界

- BizOrbit 仅为英文占位名，正式使用前须完成商标与域名冲突核查
- 保留 AIHOT 的 GitHub Fork 关系和 MIT 许可证
- 上游同步通过 GitHub Fork 的 Sync fork 或 gh repo sync 按需执行；定制内容放在独立功能分支或插件模块，不自动覆盖 main
- 本阶段不包含 Vercel 部署、外部 Worker、私有信源、客户数据或公司资料
